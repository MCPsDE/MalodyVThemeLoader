# Native desktop redesign

Mode: Operate. Chinese Windows x64 utility for Malody V players and theme authors.

THESIS: Make installation and choosing a theme immediate. Keep configuration and removal separate from normal theme selection.

OWN-WORLD: Fluent 2 neutral layers, Windows 11 Mica where available, dark neutral text and one restrained brand-blue action color; native window frame and dialogs, consistent Chinese typography, source-derived theme imagery, flat sections and fine rules.

STORY: The installer recognizes the game, explains whether BepInEx will be reused and installs offline. The manager shows a real theme preview, lets the user apply/import/export ZIPs, and offers settings and maintenance on separate pages. No agreement or device restrictions.

FIRST VIEWPORT: Installer title, explicit game path, environment diagnosis, detailed progress and a stable bottom action. Manager navigation at left, searchable theme library, selected-theme artwork and metadata at right, operation feedback at bottom.

FORM: Native task workspace selected from the existing application's actual workflows. Implementation is code based; no generated mockup or approved comp. Layout responds to resizing and retains native keyboard focus, scrollbars and dialogs.

Workflow record: This session applied the skill's native Operate guidance directly to the existing WinForms applications. It did not run concept-seed, a browser decision page or an image comp tournament; the user authorized completing the refactor autonomously, and the optional preference question received no answer. That is a disclosed deviation from the skill's full visual-world workflow, not an asserted skill exemption or a fabricated seed. No standing image/code preference was saved for the user.

QUALITY BAR: At supported normal and minimum window sizes, the primary task remains visible and controls do not overlap. Search has a persistent label. Empty, invalid, busy and disabled states remain truthful and recoverable. Shared buttons paint cleanly against their actual surface. Real artwork comes from the source; no generated rasters ship. Keyboard focus and native affordances remain available. Technical checks validate ZIP packages, install ownership, runtime reuse and rollback; synthetic scale tests are reported within their actual limits.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Evidence: screenshots from native Form.DrawToBitmap in temporary storage (desktop, minimum, 150% layout stress, settings, maintenance, empty search and installer diagnoses). No HTML/CSS detector applies to WinForms. 150% screenshots are a layout scaling stress test, not a claim of physical multi-monitor DPI verification.
