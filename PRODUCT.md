# Malody V ThemeLoader

<!-- impeccable:product-schema 1 -->

## Platform

Windows x64 desktop, native WinForms.

## Users and purpose

Malody V players install a visual theme loader once, then launch the original game normally. Theme authors import, export and edit ZIP themes, including the original Default resources.

## Stack and constraints

C#; .NET 8 WinForms installer and manager; BepInEx 6 IL2CPP plugin targeting .NET 6. Offline self-contained installation. Chinese interface. Existing compatible BepInEx is reused. No agreements, forced reading or device authorization. Missing theme resources fall back to game assets. Source and installed reference game are read-only during development.

## Workflows

Select game directory, inspect environment, install or repair. Browse themes, preview, activate, import/export ZIP and manage runtime settings. Maintenance actions are separate from everyday theme selection. No automatic game launch.

In “资源编辑”, choose an editable theme and find an image or UI-audio event through the directory tree and labeled search. Image authors compare the source and stretched preview, choose a global, scene or exact-control scope, and import a replacement. The same source image can have independent files and slice borders in different scenes or controls. Exact-control rules inherit from scene rules, then global rules, then the theme's original image or game asset. Double-clicking a source usage reads its scope directly; manually entered paths and component types require “读取此范围” before import or save. “取消定位” retains the loaded scope and its resource draft. Static usage listings cover direct serialized scene references; they do not enumerate every dynamic prefab or provide a full game-scene preview.

Optional nine-slice editing offers draggable guides, four pixel margins and a target-size preview; known RawImage targets show the whole texture instead. UI audio supports nine built-in SoundManager events and result-screen music_finish, with OGG Vorbis, WAV and MP3 import, waveform preview and audition/stop. Filenames remain readable while stored replacement paths use content hashes. Runtime playback uses separate AudioSources and the original UI-effect volume; result music uses its caller's volume. Library music, song previews, chart audio and hit sounds remain outside this workflow.

Imports and slice changes remain drafts until “保存并实时应用” commits them, activates the theme and enables real-time loading. Navigation confirms discarding unsaved changes; failed validation keeps the draft. “恢复此范围” removes only that rule and restores inheritance. A clean F5 or same-theme refresh reloads external rule changes, while a dirty draft is retained. Editing an older ZIP materializes a directory, and activation refreshes the theme library to that directory.

“资源编辑” has “资源文件” and “在线调试” modes. Online mode leases a local connection to the running loader and shows a searchable hierarchy of the current non-gameplay scene, with optional hidden nodes. Connection status reports that scene, the running theme, node count and incomplete snapshots. Only the selected node receives a 4 px yellow outline and a single 16 px name label with a dark plate; both can be disabled independently. Scene changes clear the prior selection. Authors select in the tree or middle-click a visible game region; repeated clicks at the same place cycle overlapping nodes. Picking respects UI clipping and does not require an interactive image. A picked image opens “资源文件” at its catalog resource, scene, component and hierarchy, carrying an exact node address so reused images and same-name siblings remain independent. Unsaved drafts require a discard decision before changing selection or modes.

The resource editor lists every saved replacement for the selected source image or UI-audio event in “已保存的替换”. “新增场景替换” opens the scene chooser; saving another scene retains previous scenes, and selecting an existing scope restores that scope's file, preview and slicing. “恢复此范围” removes only that scope. Lobby and song selection use distinct scene names.

Inspection middle-clicks stay with the inspector so open UI panels remain in place while picking. Ordinary left-click interaction passes through after the brief capture/release window. The live-tree search keeps its visible “搜索节点名称或路径” label when text is entered.

Optional “穿透搜索” replaces the hierarchy with a front-to-back candidate list for every active UI rectangle under the game pointer, including obscured, transparent, disabled-image and masked nodes. It defaults off, uses the existing bounded snapshot cadence, retains candidates when returning to the manager, and clears them on scene changes, disconnection, lease expiry or disabling the mode. Candidate labels include component type; full hierarchy and stable duplicate-aware addresses remain available in tooltips and details. Text search filters candidates, and either list selection or repeated middle clicks selects one node. Only that node is outlined, using its full rectangle in this mode, with one name plate. The inspector remains open until “定位图片资源” is chosen. Inactive, uninstantiated and zero-size nodes have no pointer hit region.

The 2.6.1 correction keeps bounds active when a label font is unavailable and retries node names when a usable font becomes available. Closing the inspector preserves the game's borrowed font assets.

UI nodes with a RectTransform under a Canvas can receive a background and a looping VP8 WebM video, including containers with no original image. Import accepts an image or GIF first frame for a PNG background; optional nine-slice margins use the shared preview and numeric controls. Video retains per-pixel alpha and adds 0–100% opacity, with no video audio playback. Stretch, contain and cover apply to media; width and height default to following the node, while a zero-sized node needs explicit dimensions. Nodes without a UI region remain inspectable with decoration actions disabled.

“保存并实时应用” atomically commits the node rule, activates the theme and enables live loading; “恢复此节点” removes only that decoration. Saved media follow the target's position, size, visibility and lifecycle. Hidden targets pause video; a pending or failed video retains the background, and disposal releases the added media. Disconnecting removes debug geometry while saved theme effects continue. The local lease expires after five seconds without renewal and prevents competing managers from claiming the same connection. Scene and escaped exact-node addresses persist across sessions; transient runtime instance IDs do not define saved rules. Format version 1 remains compatible with optional node rules and ZIP media export. Detailed authoring and identity rules are in `docs/SCENE_INSPECTOR.md`.

In the Live2D workbench, choose an editable theme, import a model directory or ZIP, choose a discovered model, and adjust size and position. “预览与绑定动画” opens a real Cubism model and motion preview. Draw rectangular click regions, name them, assign animations and test them on the model. Regions and motion choices are manual; body parts, HitAreas and motion names do not create automatic assignments.

Bind looping idle, clicks outside assigned regions, M1–M5 result-display events and custom regions. Each animation can carry OGG Vorbis or WAV audio, shared wherever that animation is reused. Audition plays the animation with its audio; changing playback stops the previous sound. “完成绑定” validates and returns a draft to the workbench. “保存并应用模型” commits the complete binding and activates the theme. Restore removes the model replacement; concise status distinguishes unapplied edits, saved configuration and the game's reported loading result.
