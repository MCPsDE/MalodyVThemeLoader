# Malody V ThemeLoader 2.6.11

- 新增文字配色编辑：UGUI／TMP、HEX／RGB、普通／选中／悬停、可选不透明度与恢复原色。
- GLOBAL／REALTIME／LOCAL 切换后继续使用主题颜色，默认保留透明度动画。
- 支持富文本保留／统一颜色、脚本状态颜色映射，TMP 四角渐变、独立面色与描边颜色。
- 规则可精确到单个节点，或明确选择重复列表祖先范围；调试搜索支持实际显示的文字。
- 新增「资源编辑 → 开屏动画」，支持静态图片和无声 VP8 WebM，可设置填充、背景色及时长；开屏资源随主题 ZIP 保存。
- 文字和节点底图／视频分开编辑，共用固定保存、恢复区域；沿用明暗外观和统一数值控件。

安装更新后请重启游戏一次。文字配色保存后实时应用，开屏设置在下次启动生效。开屏覆盖在插件启动后生效，插件接管前的引擎原生启动阶段仍由 Unity 管理。文件错误时保留原有呈现，不阻断游戏初始化。

保留 2.6.10 的独立 Windows 动画语音输出及既有图片、音频、Live2D、调试与自动更新功能。
