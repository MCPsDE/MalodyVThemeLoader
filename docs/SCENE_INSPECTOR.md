# 在线调试与节点装饰（2.6）

2.6.1 修复边框和名称在实际游戏中不显示的问题：生成接口中的 OS 字体创建方法是异常桩，旧版因此停绘。调试层改为复用已加载或内置字体；没有可用字体时保持边框并重试文字，关闭时不销毁游戏字体。

在管理器选择主题，打开“资源编辑 → 在线调试”，勾选“连接游戏”。请安装 2.6.6 并重启游戏。连接状态显示当前界面、运行主题和节点数量；左侧仅搜索当前界面的层级，可显示该界面的隐藏节点。选中节点才显示黄色 4px 边框和一个 16px 名称标签，标签带深色底板并避开屏幕边缘。切换场景清除旧选择；边框与名称可以独立关闭。

2.6.6 的节点装饰改为按规则的完整路径查找，不再每半秒重建所有场景的层级。目标场景未加载时不会遍历其他场景。制谱界面 SceneEditor 和 SceneEditorSkin 仍支持主题与调试；EditMode* 音符层与游玩音符层不参与界面扫描，避免大型谱面音符池造成卡顿。

中键选择当前鼠标位置的可见节点，同处 1.5 秒内再次按中键会轮选重叠对象。拾取不依赖 raycastTarget，因此装饰性背景也能选择；它遵守 RectMask2D 和 Mask 的位置过滤。选择图片节点会直接打开资源文件页，填写场景、控件类型和位置；保存时同时记录精确节点地址，避免同名兄弟或复用图片一起改变。也可在在线树中选择节点，再使用“定位图片资源”。未保存的修改需要用户决定是否放弃。

### 鼠标穿透搜索（2.6.5）

勾选“穿透搜索”，把鼠标移到游戏中想找的位置。左侧列出该位置下所有有有效矩形区域的活动 UI 节点，包括被其他图片盖住、图像透明或禁用、CanvasGroup 透明以及被 Mask / RectMask2D 裁掉的节点。按画布层级、绘制深度和子节点顺序排列；同名节点分别保留，悬停列表项可查看完整路径和地址。上方文字搜索继续过滤此候选列表。

鼠标移回管理器时保留最后一次结果，直接点选即可；也可在游戏中连续按中键轮选。此模式保持在线调试页，使用“定位图片资源”再进入资源文件页。游戏只画选中节点的完整矩形边框和一个名称，不会把所有候选名称叠在一起。关闭“穿透搜索”立即恢复普通树和可见区域选取；断开连接、租约过期或切换场景清除旧候选。未连接或旧插件不支持时显示等待状态。

搜索只枚举当前场景已存在的实例，不创建或激活游戏对象。`itemScore` 是成绩列表动态生成的预制体，只有该列表创建了对应行之后才有运行节点（通常名为 `itemScore(Clone)`）；未生成的预制体、inactive 对象、零尺寸区域不会出现在鼠标候选中。inactive 对象仍可关闭穿透搜索后，通过“隐藏节点”和名称搜索查看。

调试 Canvas 使用加载器自己的原生透明 Image 和 GraphicRaycaster，配合注入的轻量 MonoBehaviour / ICanvasRaycastFilter，只在中键及紧随其后的释放帧接收 UI 射线；普通左键继续到达原 UI，游玩场景不启用拦截。这样不会因原游戏 UIHalfPanel 的任意按钮点击处理而在拾取时关闭面板，也不修改游戏输入派发方法。隔离 Unity 验证实际射线排序和普通点击穿透。

有 RectTransform 和 Canvas 的节点可以添加底图与视频，包括没有原图片的容器。没有 UI 区域的逻辑或模型节点保留在树中供检查。宽高为 0 表示跟随原区域；原区域为零尺寸时需输入宽高。底图支持 PNG/JPG/WebP/GIF 首帧/BMP，保存为 PNG，可设置九宫格切片。视频使用 VP8 WebM，支持其自身 Alpha 与 0–100% 不透明度；VP9 会给出转为 VP8 的提示。拉伸、完整显示与裁切填满同时用于底图和视频。视频音轨不播放。

“保存并实时应用”原子提交规则，启用此主题和实时模式。“恢复此节点”只移除此节点的装饰。图层跟随目标移动、尺寸、显隐和场景生命周期；隐藏时暂停视频，销毁或主题重载时释放。视频首帧就绪前保持底图，解码失败时保留底图并显示失败状态。关闭调试连接只移除调试线框，已保存主题效果继续生效。

## 存储与身份

主题和 resources.json 的 formatVersion 仍为 1，新增可选 nodes 列表。文件相对于主题 imageRoot 存储，导入文件按内容 SHA-256 命名；名称独立记录，导出 ZIP 保留全部规则和媒体。

```json
{
  "formatVersion": 1,
  "nodes": [{
    "scene": "SceneSong",
    "address": "Canvas#0:1/Panel#0:1",
    "hierarchy": "Canvas/Panel",
    "imageFile": "overrides/<hash>.png",
    "videoFile": "overrides/<hash>.webm",
    "videoOpacity": 0.45,
    "fit": "contain",
    "width": 0,
    "height": 0
  }]
}
```

地址的每一段由 URI 转义的实际名称、同名兄弟序号及同名数量组成。不同名称的邻居插入不会影响地址；同名数量变化时旧地址不匹配，防止错误套用。InstanceID 只用于当前连接，游戏重启后重新按场景与地址关联。旧图片规则继续按原方式继承；精确节点图片规则增加 nodeAddress，并在运行时组件匹配时获得最高优先级。

管理器单写 ThemeLoader/inspector/control.json，以租约、客户端 ID、运行会话和请求号交换选择；插件在 Unity 主线程读取并发布 snapshot.json。2.6.2 起除界面更新外，独立后台每秒续期，打开文件对话框或长操作不会中断；超过 5 秒或显式断开时清除线框，多管理器拒绝争用已有连接。层级快照约每 0.5 秒更新，已有边框逐帧跟随。瞬时读取失败保留尚有效的控制快照，过期后仍停绘；场景节点或绘制资源失效后，一秒后自动重建重试，重复日志十秒限频。节点数量超过 20,000 或深度超过 96 时标记不完整，界面明确显示。调试通信路径不触发主题重新加载。

当前仅发现 active scene 的非游玩节点，后台场景、持久对象和资源预制体不加入调试树，不为了调试强制加载其他场景，不访问判定、谱面输入或提交逻辑。普通 Transform 没有二维区域时不伪造边框。嵌套 Mask 的边框是区域边界，复杂遮罩的像素形状不作为线框轮廓。画面投影模式的鼠标位置会先反投影到原界面再拾取。快照写入遇到临时文件锁时延后重试，保留覆盖层和选择，不触发销毁重建。

## 验证

- test-inspector-il2cpp.ps1：构建独立 IL2CPP 测试播放器，加载固定 BepInEx 785 与未适配的生产定位、装饰和调试源代码，进行 600 次拾取、100 次底图重载，并主动触发 .NET / IL2CPP 双端 GC；检查原生 Image 与过滤接口、唯一线框和标签。现有隔离播放器可用 `-SkipPlayerBuild` 复用。测试 Unity 版本是 2022.3.62f3，不等于实际游戏 f2/Metadata V29 和玩家其他插件的完整组合。
- test-scene-inspector.ps1：明暗、正常/最小窗口与合成 150%，实时树、搜索、隐藏节点、底图/视频、透明度、编码失败不覆盖、精确资源跳转、同名隔离、启用主题与实时模式、恢复和 ZIP。
- test-inspector-runtime.ps1：独立 Unity 2022.3.62f3 播放模式，使用经适配的生产节点定位、装饰及调试绘制代码。真实 VP8 Alpha 解码、底图与 45% 视频叠加像素、前景保留、Mask 拾取、中键轮选、双向选择、线框/名称绘制、租约失效及失败清理均有断言。Mono 测试替换 IL2CPP 数组/委托封装及原子写入重载；不替代发行插件的真实 interop 校验。
- 加 `-Standalone` 可构建独立 Windows Mono 播放器，在不切换到用户桌面的独立 Windows desktop 中运行，验证真正 ScreenSpaceOverlay 最终屏幕的边框与文字像素，以及字体缺失/恢复和借用字体的生命周期；2.6.1 通过 33 项断言。此播放器使用自己的测试场景，不运行 Malody V。

开发不操作已安装游戏；隔离工程测试与静态接口校验不等于实际 IL2CPP 游戏端到端运行。合成缩放不代表物理显示器 DPI 检查。WebM 支持以 Unity 2022.3 的 VP8 Alpha 路径为基准，参考 [官方编码说明](https://docs.unity3d.com/2022.3/Documentation/Manual/VideoTransparency-codecs.html)。
