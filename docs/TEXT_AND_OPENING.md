# 文字配色与主题开屏 · 2.6.11

## 修改文字

1. 更新并重启游戏，选择要制作的主题。
2. 在「资源编辑 → 在线调试」开启连接。可按节点名称、路径或实际显示的文字搜索；也可在游戏中按中键选中节点。
3. 选中文字节点后，右侧默认打开「文字配色」。「底图与视频」仍可为同一节点添加背景。
4. 输入 `#RRGGBB`，或展开 RGB 数值，也可点击选色。底部「保存文字配色」实时应用；「恢复原色」只移除此文字范围。

支持 UGUI `Text` 和 `TMP_Text`。普通颜色必填，选中／悬停颜色可留空继承。悬停优先于选中，选中优先于普通颜色。GLOBAL、REALTIME、LOCAL 的选中态来自游戏已显示的分类背景；Toggle 来自自身显示状态，其他 Selectable 来自当前 UI 选择。只观察表现状态，不更改分类配置、切换或请求行为。

默认保留组件当前 Alpha、悬停渐变和父 CanvasGroup 淡入淡出。「覆盖文字不透明度」会固定组件 Alpha，父级 CanvasGroup 仍由游戏控制。

富文本默认保留分段颜色。「统一富文本颜色」通过 TMP 的颜色标签覆盖选项，或仅移除 UGUI 的 `<color>` 标记实现；加粗等格式、最新文字内容与本地化更新继续保留。恢复时回到游戏最新的原始标记与颜色，不冻结首帧文字。

TMP 的更多设置提供保留渐变／纯色／自定义四角渐变，以及可选面色和描边颜色。四角依次是左上、右上、左下、右下；渐变与基础文字颜色按 TMP 原规则相乘。描边颜色沿用原材质的描边宽度。每个目标克隆自己的材质，面色和描边 Alpha 保留，恢复、场景退出与重载时归还原材质并释放克隆，不改共享字体。

脚本会切换不同颜色的文字，可在「更多配色设置」中每行填写 `#原色 = #替换色`，最多 32 对，不重复原色。匹配游戏写入的原始 RGB，随后仍可由选中／悬停颜色覆盖。

「仅此节点」保存场景、完整地址、同名数量与组件类型。列表里有重复行时，可明确选择一个重复祖先的所有同级实例；只放开那一段的序号和数量，其余路径保持精确。新增／回收行可以继续匹配，其他场景与分支不受影响。精确规则优先于模板；模板相互冲突时不应用，避免猜测目标。恢复模板会移除此模板范围，其他单独规则继续保留。

文字摘要用于搜索；只有当前选中的节点读取详细材质与渐变。运行时仅维护已绑定组件，并每 0.75 秒按规则路径发现新实例；不逐帧全局查找文字，不进入游玩场景或 `EditMode*` 音符层。

## 设置开屏

在「资源编辑 → 开屏动画」中选择主题并导入 PNG／JPG／WebP／BMP 或 VP8 WebM。图片统一存为 PNG；文件复制到主题的 `images/overrides`，不依赖原导入位置，ZIP 导入导出会保留资源与配置。预览图片直接显示，视频由「预览文件」交给本机播放器。

可选完整显示、裁切填满、拉伸填满，设置背景颜色及 1–30 秒最长时长。WebM 无声播放，不循环，播放完成后自动关闭；静态图显示到设定时长。保存或恢复均在下次启动游戏时生效，实时重载不会反复播放开屏。

开屏是插件持有的独立覆盖层，不修改游戏初始化、场景切换或加载逻辑。媒体准备完成前保持原有画面，准备失败、文件缺失、损坏或超时则回退。视频播放器、纹理和覆盖层在播放结束／重载时释放。BepInEx 插件只能接管其启动后的呈现；在插件执行之前已经出现的 Unity 原生／系统启动画面无法倒退替换。没有通过修改游戏核心文件或延迟初始化来掩盖这一限制。

## 配置与兼容

规则仍在主题 `resources.json`，保留 `formatVersion: 1`；旧主题缺少 `texts`／`opening` 时继续按原方式加载。文字规则不需要额外图像文件，开屏资源按内容哈希存放。重载、关闭主题与恢复保持现有图片、字体、Live2D、节点装饰和音频规则互不覆盖。

验证入口：`scripts/test-text-opening-editor.ps1` 与 `scripts/test-text-opening-il2cpp.ps1`。前者在独立桌面的 .NET 8 WinForms 消息循环内检查明暗、常规／最小尺寸与合成 125／150／200% 缩放；后者使用隔离 Unity 2022.3.62f3 IL2CPP 播放器验证实际原生组件生命周期。实际游戏为 f2，两者不等同，真实游戏目录保持只读。
