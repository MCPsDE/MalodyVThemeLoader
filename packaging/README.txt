安装
----

1. 关闭游戏。
2. 运行安装程序并连续完成三遍条款阅读。
3. 选择包含“Malody V.exe”的游戏目录。
4. 点击“安装 / 修复”。

安装程序不会启动游戏。完成后，桌面会出现“主题管理器”快捷方式。游戏
仍从 Steam 或原始 Malody V.exe 正常启动。

主题管理
--------

Theme Pack 使用 `.mtp` 后缀。它本质上是经过安全校验的 ZIP 压缩包，
根目录必须包含 theme.json。

从桌面快捷方式打开主题管理器后，可以：

- 导入或拖入 Theme Pack。
- 查看主题名称、版本、作者、游戏版本、说明、文件数量和原始 JSON。
- 将选中主题设为当前主题。
- 启用或关闭“实时模式”；启用后，运行中的游戏会尝试在主题文件变更时
  自动热重载。
- 导出已安装主题；旧式主题文件夹会自动打包为 Theme Pack。
- 移除单个主题或清空所有导入主题并恢复 Default。
- 按安装清单执行完整卸载。

主题存储位置：

ThemeLoader\themes

当前主题记录：

ThemeLoader\active-theme.txt

实时模式设置：

ThemeLoader\settings.json

缺少的图片、字体或 Live2D 文件会继续使用原始资源。Theme Pack 不得包含
网络图片、歌曲封面、用户皮肤、下载内容或无权分发的官方资源。

动态背景
--------

主题可以把支持的背景或 UI 图片替换为循环视频。视频文件与静态图片使用
同一个逻辑路径，只把扩展名改为下列三类之一：

- .mp4
- .webm
- .ogv

例如原静态图片路径为：

images\Textures\Malody\mainlist_bg2.png

动态版本可以放为：

images\Textures\Malody\mainlist_bg2.mp4

如果同一逻辑路径同时存在静态图片和视频，运行时会优先尝试视频替换；
无法应用视频时仍保留原始游戏资源或静态替换。视频会静音并无限循环。
建议优先用于全幅背景和完整矩形 UI 素材，复杂九宫格、边框切片或特殊
材质素材仍应在游戏内逐项验证。

协议与设备授权
--------------

安装器每遍条款需要等待 60 秒并滚动至末尾。主题管理器每次启动会显示
三遍条款，无等待时间，可以立即继续。运行时插件还会校验设备授权和
签名条款凭据；任一校验失败时不会安装主题补丁，原始资产保持不变。

设备授权是用于限制随意复制的本地措施，并不可能对控制本机的专业逆向
人员提供绝对保护。它也不替代游戏或素材权利人的许可。

日志
----

BepInEx 运行日志位于：

BepInEx\LogOutput.log

卸载
----

推荐从桌面主题管理器使用“完整卸载”。也可以重新运行安装程序并选择
“卸载”。安装器只删除清单记录且哈希仍匹配的文件；被用户修改或不再
归安装器所有的文件会保留。
